# Дизайн-гайд карточек Swag AI

> Зафиксировано 25.08.2026. Референсы: визитка **LUMA** (чёрный фон, аврора-градиент,
> крупная типографика, uppercase-детали, хэштег внизу) и формат канала **neuralBox**.
> Рендер: Pillow (`swag/renderer.py`), без браузера — быстро и CI-friendly
> (Playwright отклонён: ~2 с/карточка + Chromium 300 MB в CI).

## Холст

- **1280×720** PNG (16:9 — крупный превью-кадр в ленте Telegram)
- Фон: near-black `#060606` (аврора «светится» только на тёмном)

## Аврора-градиент (подпись стиля)

Три размытых цветовых пятна в левой-верхней зоне (за заголовком):

| Пятно | Цвет | Прозрачность |
|---|---|---|
| верхнее | `#FFE95C` (жёлтый) | 200 |
| среднее | `#FF5A3C` (красно-оранжевый) | 170 |
| нижнее левое | `#3DDC84` (зелёный) | 150 |

GaussianBlur **110** — именно сильное размытие превращает пятна в «северное сияние».
Правило: **максимум 3 оттенка**, больше — цвета грязе-коричневые.

## Типографика — Inter (variable, `assets/fonts/Inter.ttf`)

| Элемент | Начертание | Размер | Цвет |
|---|---|---|---|
| Шапка `SWAG AI — FREE AI RADAR` | Regular, трекинг 5px | 22 | `#6E6E6E` |
| Заголовок (название репо / RU-заголовок) | **Bold**, автоподбор 92→46px, ≤ 3 строки | — | `#F5F5F5` |
| Описание (RU-пересказ) | Regular, ≤ 3 строки | 30→20 | `#B2B2B2` |
| Строка статистики `STARS 149 · FORKS 11 · PYTHON` | Regular, uppercase, трекинг 5px | 26 | `#F5F5F5` |
| Хэштег `#SWAGAI` внизу по центру | Regular, трекинг 5px | 24 | `#B2B2B2` |

## Контент карточки

- **github**: заголовок = имя репо (или RU-вариант от LLM), описание = RU-перевод описания,
  статистика = STARS/FORKS/LANGUAGE из API, ссылка в caption — «Открыть на GitHub»
- **news**: заголовок = RU-заголовок от LLM, описание = RU-пересказ, статистика = `AI NEWS`,
  ссылка — «Читать»

## Caption под картинкой (≤ 1024 симв.)

Заголовок-ссылка → описание → метрики → инлайн-ссылка → хэштеги из топиков.
Карточка дублирует заголовок картинкой — caption можно читать без раскрытия фото.
