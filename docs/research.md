## 1. Можно ли хостить бота на Vercel? → Нет (для нашего случая)

| Ограничение Vercel Hobby (free) | Значение | Последствие |
|---|---|---|
| Cron jobs | **1 запуск в день**, выражения чаще фейлят деплой с ошибкой `Hobby accounts are limited to daily cron jobs` | Парсинг раз в 15–60 мин невозможен |
| Точность cron | ±59 минут, только UTC | Даже ежедневный пост придёт «когда-нибудь в течение часа» |
| Функции | serverless, default timeout 30s (до 300s) | Нет постоянного процесса |
| Смена расписания | редеплой (правка `vercel.json`) | Неудобно |

Webhook-бота на Vercel задеплоить можно (гайд grammY: grammy.dev/hosting/vercel),
но наш сценарий — **фоновый парсер по расписанию**, а не реакция на запросы.

Обходной путь «внешний cron пингует endpoint» (Crontap и т.п.) существует, но это
лишняя зависимость и костыль — проще взять хостинг с постоянным процессом.

Источники: vercel.com/docs/cron-jobs/usage-and-pricing, vercel.com/docs/plans/hobby,
vercel.com/docs/limits.

## 2. Альтернативы (сравнение 2026)

| Платформа | Free в 2026 | Цена старта | Комментарий |
|---|---|---|---|
| **Render** | ✅ единственный настоящий free (750 ч/мес), но web-service **засыпает через 15 мин** простоя, cold start ~минута | $7/мес за always-on сервис | Для фонового воркера 24/7 бесплатно не подходит |
| **Railway** | ❌ free tier убран (2023); one-time $5 trial кредит (~30 дней) | Hobby $5/мес (включает $5 кредита) → реально $6–9/мес | Лучший DX, деплой из GitHub в минуту |
| **Fly.io** | ❌ free allowances убраны (10.2024), только trial | ~$3.3/мес за 512 MB machine | Самый дешёвый always-on; CLI-first |
| **Oracle Cloud Free Tier** | ✅ бесплатная VM навсегда (ARM Ampere) | $0 | Лучший бесплатный вариант, но нужен аккаунт и настройка VM |
| **Свой ПК + Docker** | ✅ | $0 | Для разработки и первого запуска |

Источники: expresstech.io «Render vs Railway vs Fly.io: 2026 Pricing Showdown»,
saaspricepulse.com, dev.to (2026).

**Решение:** разработка локально → прод на Railway/Fly (~$5/мес) или Oracle Free VM ($0).

## 3. Telegram Bot API — ключевые лимиты

- **Caption** к фото/видео/документу: **1024 символа** после парсинга entities — жёсткий лимит,
  при превышении API возвращает 400 → обрезать на нашей стороне.
- Обычное сообщение: 4096 символов.
- Фото через `sendPhoto`: до 10 MB (больше — только `sendDocument`, без превью).
- Rate limits: ~30 сообщ/сек глобально, **~20 сообщ/мин в один канал** — для нас не проблема
  (единицы постов в час).
- Публиковать в канал бот может только будучи **администратором** канала.
- `sendPhoto` поддерживает `reply_markup` с инлайн-кнопками (как «Открыть на GitHub» у neuralBox).

Источники: core.telegram.org/bots/api, gramio.dev/telegram/methods/sendPhoto, limits.tginfo.me.

## 5. LLM для русскоязычных саммари (free tier)

| Провайдер | Free-лимиты (2026) | Карта | Вывод |
|---|---|---|---|
| **Google Gemini Flash** (AI Studio) | ~10–15 RPM, ~**1500 req/день**, 1M контекст | не нужна | ✅ основной выбор: запас огромный (наш объём — десятки запросов/день) |
| Groq | 30 RPM, ~1000 req/день, Llama 3.3 70B | нет | запасной №1, очень быстрый |
| Cerebras | 5–30 RPM, ~1M tokens/день | нет | запасной №2 |
| OpenRouter | 20 RPM, 50 req/день free (1000/день после разового $10) | нет | единый ключ к 20+ бесплатным моделям, failover |

Подводные камни Gemini:
- Лимиты **per-project**, а не per-key — дополнительные ключи в одном проекте не увеличивают квоту.
- **Включение биллинга проекта полностью отключает free tier** (все вызовы платные с первого токена).
  Держать отдельный проект без биллинга для бесплатного использования.
- Квоты RPD сбрасываются в полночь по тихоокеанскому времени, Google менял квоты без предупреждения
  (сокращение в дек. 2025; Pro-модели убраны из free tier с 01.04.2026) → абстракция провайдера LLM
  в коде обязательна.

Источники: ai.google.dev/gemini-api/docs/pricing, usagebox.com, openrouter.ai/blog, klymentiev.com (2026).

## 6. Рендер карточки (как у neuralBox)

- **Вариант A (рекомендован):** HTML/CSS-шаблон → скриншот через Playwright/Chromium.
  Плюсы: вёрстка любой сложности (тёмная тема, лого, метрики, теги — как в референсе),
  правится как обычная страница. Минусы: тяжёлый Chromium в контейнере (~300 MB).
- **Вариант B:** Pillow (Python) — легко, но каждая деталь рисуется вручную.
- Требования к картинке: PNG/JPEG ≤ 10 MB; для карточки 1080×608 хватит с запасом.

## 7. Бесплатный хостинг 24/7 — детальный разбор (обновлено 25.08.2026)

Задача: гонять Python-парсер бесплатно. Проверено по свежим источникам:

### ✅ Oracle Cloud Always Free — основной вариант
- VM навсегда ($0, не trial): ARM Ampere A1 + 2× AMD E2.1.Micro (1/8 OCPU, 1 GB каждый).
- **Важно (авг. 2026):** квота A1.Flex урезана с 4 OCPU/24 GB до **2 OCPU/12 GB** на тенанси,
  принудительно применяется с 18.08.2026 (были случаи отключения даже формально валидных VM).
  E2.1.Micro не тронуты. Для нашего парсера 2 OCPU/12 GB — с огромным запасом.
- Риски: простой VM могут реклеймить → лёгкий keep-alive cron; при регистрации нужна карта;
  ARM64 (Python — без проблем).
- Источники: oracle.com/cloud/free, dev.to «How to Check If Your Oracle Cloud A1 Free Tier
  Instance Just Got Quietly Downgraded» (21.08.2026).

### ✅ GitHub Actions cron — запасной вариант без сервера
- Публичный репо: **бесплатно и безлимитно**. Приватный на free-аккаунте: schedule-триггеры
  **отключены** (недокументированное ограничение; нужен GitHub Pro $4/мес, публичный репо
  или внешний cron → `workflow_dispatch` API).
- Реальная частота: заявленное расписание — верхняя граница; замеры показывают троттлинг
  (заявлено 4/час → реально 1–2/час, бывают задержки до 8–14 ч в пике).
- Для нас приемлемо: пайплайн идемпотентен (дедуп в SQLite), пропуск запуска = чуть более
  поздний пост. Состояние — коммит `data/swag.db` обратно в репо из workflow.
- Источники: devactivity.com (07.08.2026), dev.to/rulestack (21.08.2026).

### ❌ Отпавшие
| Платформа | Причина |
|---|---|
| Render free | засыпает через 15 мин простоя, cold start ~1 мин |
| Koyeb free | 1 сервис, scale-to-zero через 1 ч без трафика, нельзя отключить |
| PythonAnywhere free | 100 CPU-сек/день, задачи по расписанию — раз в день |
| Railway / Fly.io | free tier убраны (2023/2024) |
| Cloud Run + Cloud Scheduler | free квоты есть, но требуется платёжный аккаунт (карта) |

### Итог (решение 25.08.2026)
1. Разработка: локально, `DRY_RUN=1`.
2. **Прод: GitHub Actions cron в публичном репо** — выбран пользователем: полностью
   бесплатно и без регистраций на облачных платформах. Oracle отклонён (нужна регистрация
   с картой). Workflow: `.github/workflows/parser.yml`, состояние — `state/swag.db`
   коммитится обратно в репо.
